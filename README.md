## About me

I'm **Caique Rechi Mehret**, a Brazilian software developer with **5+ years of experience** building and evolving production web applications, REST APIs, payment integrations, and internal business systems.

My work spans **full-stack development, software architecture, and integrations**, with a strong focus on PHP and Laravel. I enjoy making complex business rules easier to maintain, improving existing systems, and building tools that help developers work better.

## Technical expertise

**Backend:** PHP · Laravel · REST APIs · Webhooks · Payment Flows · MySQL · Redis

**Frontend:** React · TypeScript · JavaScript · Inertia.js · Tailwind CSS

**Engineering & infrastructure:** Docker · Git · GitHub Actions · CI/CD · Automated Testing · Static Analysis · Observability

## Selected projects

### [Rechi — Portfolio](https://github.com/CaiqueRechi/Portifolio)
Full-stack portfolio and application built with **Laravel, React and Inertia**. Includes access control, external integrations, encrypted credentials, Redis, automated tests, static analysis, and CI/CD.

A Laravel API dedicated to managing the **payment lifecycle**, with auditable status histories and automated tests.
